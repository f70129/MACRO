# 投資看板專案

本 repo 包含兩個獨立的 Streamlit 看板,共用同一份 `requirements.txt`:

| 主檔案 | 看板 |
|---|---|
| `app.py` | 台指期貨 & 台灣加權指數 費氏數列 × 移動平均 分析看板 |
| `macro_app.py` | 🌐 總經週期追蹤看板(官方來源版) |

## 🌐 總經週期追蹤看板(macro_app.py)

### 設計原則
1. **不使用第三方 API、免金鑰、免註冊**:只用官方檔案下載端點
   - FRED 官方 CSV 下載連結(等同官網「Download CSV」按鈕)
   - 台灣證交所 MOPS 官方月營收報表檔(`t21sc03_{民國年}_{月}_0.html`)
   - Yahoo Finance 公開報價(僅作市場代理,非核心數據)
2. **ISM 處理方式**:ISM PMI 為 ISM 協會的授權調查數據,**無法由其他數據計算還原**。
   本看板改用官方免費、同性質的擴散指數調查:紐約 Empire State、費城聯儲、達拉斯聯儲
   製造業調查(0 ≈ ISM 的 50,與 ISM 高度相關且更早公布);
   「新訂單−庫存 Spread」以費城聯儲子項目直接相減;
   另以 Census 耐久財新訂單、工業生產、存貨銷售比等**硬數據**交叉驗證。
3. **不容許錯誤數據**:
   - 每條序列驗證「數值合理範圍 + 日期新鮮度」,不合格 → 顯示「不可用」,絕不顯示錯誤數字
   - FRED 回應需通過欄名 = 序列代碼防呆檢查,避免錯誤頁面被誤判為數據
   - 台股營收 YoY 以 MOPS 官方檔內「去年同月增減(%)」欄位交叉比對自算值(容差 ±0.5pp)
   - 頁面內建「🔍 資料健康度面板」:每條序列的來源 / 代碼 / 最新日期 / 驗證狀態,可逐條稽核
   - 綜合指數僅使用通過驗證的成分,且至少 3 項才計算(寧缺勿錯)

### 追蹤模組(5 個分頁)
1. **製造業週期綜合指數** — 通過驗證成分之 Z-Score 平均 + 週期位置判定(復甦/擴張/趨緩/收縮)
2. **美債 10Y-2Y 利差** — 含 NBER 衰退灰底(倒掛→翻正,歷史勝率 ~85%,領先 6-18 個月)
3. **流動性** — 美國 M2 YoY、FED 資產負債表、ECB 資產(M2 增速拐點領先風險資產 2-3 個月)
4. **製造業調查 + 硬數據** — 地區聯儲調查、新訂單−庫存 Spread(領先 2-4 個月)、耐久財訂單/工業生產交叉驗證
5. **台灣半導體** — 台積電+聯電+聯發科月營收 YoY(MOPS 官方)+ SOX/加權指數年增率

### 六大訊號燈
殖利率曲線翻正、製造業調查穿越 0(≈ISM 穿越 50)、新訂單−庫存 Spread、
M2 增速拐點、半導體營收 YoY 翻正、多指標共振(≥80% 同向 = 高可信度確認)。

### 自動更新機制
- 總經數據快取 **6 小時**、市場數據 **1 小時**、MOPS 月營收 **24 小時**(`st.cache_data(ttl=...)`)
- 快取到期後,任何人開啟頁面即自動重抓官方最新檔案
- 側邊欄有「🔄 立即強制更新」按鈕
- 首次載入需並行下載約 60 個月的 MOPS 官方檔,約 30-60 秒;之後走快取秒開

## 🚀 部署到 Streamlit Cloud(三分鐘)

1. 將本 repo push 到你的 GitHub
2. 前往 <https://share.streamlit.io> → **New app**
3. 選擇此 repo / 分支,**Main file path** 填:
   - 總經看板:`macro_app.py`
   - 台指期看板:`app.py`
4. 按 **Deploy** 即完成,之後每次 push 會自動重新部署

## 本機執行

```bash
pip install -r requirements.txt
streamlit run macro_app.py   # 總經週期看板
streamlit run app.py         # 台指期費氏看板
```

> ⚠️ 本專案僅供研究參考,不構成投資建議。
